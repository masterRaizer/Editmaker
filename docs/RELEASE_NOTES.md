## EditMaker 1.0.0

Утилита для аниме- и dark-эдитов: исходники с SSD → 4 варианта монтажа под бит → водяной знак в ролике и в концовке → ручное одобрение → YouTube и TikTok.

### Файлы

- `EditMaker-1.0.0-x64.msi` — установка в `C:\Program Files\EditMaker`, ярлыки в «Пуске» и на рабочем столе.
- `EditMaker-1.0.0-portable.exe` — один файл без установки; первый запуск дольше, пока программа распаковывается.

ffmpeg с NVENC уже внутри. Нужна Windows 10/11 x64 и WebView2 (обычно уже есть; без него интерфейс откроется в браузере). Сборка без цифровой подписи: SmartScreen попросит «Подробнее» → «Выполнить в любом случае».

### Что внутри

- Индексация папок на SSD: название, серия, разрешение, FPS, кодек, склейки, динамика и детализация кадра.
- 4 стиля: Cold / Dexter Pace, High-Impact Beat / Drop, Smooth / Flow, Fast Hook / Retention Cut. Выбор стилей и силы эффектов.
- Склейки на долях, отрывок трека с сильной доли такта, дроп трека сразу после хука.
- Whip-переходы с направленным размытием, zoom-blur, impact-кадр на дропе, RGB-сдвиг, shake на басу, вспышки без стробоскопа, рампы скорости со смешиванием кадров или оптическим потоком.
- 1080×1920 / 1920×1080 / 4K, 60 fps, x264 CRF 16 slow (aq-mode 3) или NVENC p7, двухпроходный loudnorm до −14 LUFS.
- Водяной знак (текст или PNG) в ролике и в концовке, живое превью.
- Сравнение двух вариантов рядом, переход по склейкам, горячие клавиши.
- Экспорт в DaVinci Resolve / Final Cut (FCPXML), Premiere (EDL), пакет для CapCut.
- Публикация на YouTube (Data API v3) и TikTok (Content Posting API) только после «Одобрить». Правка текста или файла после одобрения снимает одобрение.

Установка и проверка шаг за шагом: `docs/LAPTOP_AGENT_PROMPT.md`.
